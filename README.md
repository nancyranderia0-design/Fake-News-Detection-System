# Fake News Detection System

## Project Overview
A Python-based mini project developed for GTU Semester 5 - Python for Data Science.

## Technologies Used
- Python
- Pandas
- NumPy
- SciPy
- Regular Expressions

## Features
- Dataset loading and preprocessing
- Rule-based news classification
- CRUD operations
- NumPy statistical analysis
- SciPy hypothesis testing
- CSV result export

## Dataset
Uses Fake.csv and True.csv datasets.

## How to Run
1. Install the required libraries:
   pip install pandas numpy scipy

2. Place Fake.csv and True.csv.zip
   in the same directory as the Python file.

3. Run:
   python fake_news_detection.py

## Disclaimer
Classification is based on suspicious keywords
and does not independently verify news accuracy.
